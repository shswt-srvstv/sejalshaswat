# Happy Birthday, Sejal ♥

A little birthday card website from Shaswat.

## Photos

Put your pictures in the main folder with **exactly these names**:

| File | Where it shows |
|---|---|
| `hero.jpg` | Big photo at the top |
| `photo-1.jpg` … `photo-6.jpg` | The "Us, so far" gallery |

Until a photo is added, a pink "add photo" box shows in its place, so nothing looks broken.
Portrait photos (4:5) look best. If your photos are `.png` or `.jpeg`, either rename them to `.jpg`
or change the filename in `index.html`.

## Optional: background music

Add an mp3 at `song.mp3`. It starts when she opens the envelope and a ♪ button appears to pause it.

## Edit the words

All the text (letter, captions, the 6 "reasons", the date) is in `index.html` — just search for the line and change it.

## Put it online with GitHub Pages

1. Create a new repository on GitHub (e.g. `happy-birthday-sejal`).
2. Upload **all** these files (keep the folders) to the repo.
3. Go to **Settings → Pages**, set *Source* to **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute your card is live at `https://<your-username>.github.io/happy-birthday-sejal/`.

Send her the link 🎉
